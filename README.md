Coursework Description

This repository contains five Python exercises completed for the Programming for Cyber Security module. Each exercise focuses on a different programming concept related to cybersecurity.

Exercises

1. Security Tool – A menu-driven security program that includes password checking, brute-force simulation and login authentication.
2. Security Event Logger – Records successful and failed login attempts, including relevant event details.
3. IP Address Validator – Checks whether an IPv4 address follows the required format and contains valid numerical values.
4. Security Incident Manager – Uses Python dictionaries to store, update and manage security incident information.
5. Cyber Security Utilities – Uses reusable Python functions and modules for password validation, IP checking and password generation.

Branches

Each exercise is developed in its own Git branch:

- `security-tool`
- `security-event-logger`
- `ip-address-validator`
- `security-incident-manager`
- `cyber-security-utilities`
